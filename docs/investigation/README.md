# 調査メモ

- 本 README 以外のファイルは gitignore 対象であり、リポジトリには含まれない
- 設計メモ作成時にのみ参照される。最新の仕様を把握する目的で読んではいけない
- 運用は [design-workflow.md](../workflow/design-workflow.md) を参照

## ファイル名
`<slug>.md` (slug の規則は [workflow/README.md](../workflow/README.md) を参照)
